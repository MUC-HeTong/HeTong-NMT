# HeTong-NMT

**HeTong-NMT** is the neural machine translation research and model series of the HeTong project, with a focus on multilingual and low-resource language translation.

## Projects

- **[BATA](./BATA/)** — Behavior-Aware Terminology Adaptation for low-resource Tibetan–Chinese machine translation.
- **[HeTong-NMT-7B](https://huggingface.co/MUC-HeTong/HeTong-NMT-7B)** — 7B-parameter Tibetan–Chinese bidirectional translation model.

Research code, model releases, and supporting resources are organized by project. Please refer to each project directory for implementation details, setup instructions, and usage notes.
